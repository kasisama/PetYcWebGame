# 宠物养成 · PetYC

网页版宠物养成（原 [PetYC](https://github.com/kasisama/PetYC) QQ 机器人的浏览器版）。

在线试玩：[petyc.grok.me](https://petyc.grok.me/)

## 玩法

- 领养五族宠物：光芽、苔须、烬爪、岩甲、风耳
- 喂食、梳洗、摸摸、散步，数值随时间掉落
- 探险、战斗、进化与觉醒
- 存档在本机 `localStorage`，刷新不会丢

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开提示的地址即可。生产构建：`npm run build`。
